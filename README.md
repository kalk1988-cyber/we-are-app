# We Are — ইউজার অ্যাপ + পয়েন্ট-ভিত্তিক লুডু/তাশ

একটি মাল্টি-ইউজার ওয়েব অ্যাপ:
- যে কেউ রেজিস্ট্রেশন করে অ্যাকাউন্ট খুলতে পারবে
- **প্রথম যিনি রেজিস্ট্রেশন করবেন, তিনি স্বয়ংক্রিয়ভাবে অ্যাডমিন হবেন** (এটাই হবে আপনার অ্যাকাউন্ট)
- সাইনআপ করলেই ১,০০,০০০ **পয়েন্ট** বোনাস (⚠️ এটা শুধু অ্যাপের ভেতরের ইন-গেম স্কোর/কারেন্সি — রিয়েল টাকা নয়, বিকাশ/নগদে ক্যাশ-আউট করার কোনো ব্যবস্থা এতে নেই)
- পয়েন্ট দিয়ে ব্রোঞ্জ → সিলভার → গোল্ড গেম রুম আনলক হয়
- লুডু ও তাশ (কল ব্রেক ধাঁচের, ট্রাম্প সবসময় স্পেড) — বন্ধুদের সাথে রুম কোড দিয়ে রিয়েল-টাইমে অনলাইনে খেলা যাবে
- গেম জিতলে বা অংশ নিলে বাড়তি পয়েন্ট পাওয়া যাবে
- অ্যাডমিন প্যানেল থেকে ইউজার তালিকা, পয়েন্ট, ব্যান/আনব্যান/ডিলিট ম্যানেজ করা যাবে

## ⚠️ কেন এতে রিয়েল টাকা / বিকাশ-নগদ নেই

টাকা জমা-উত্তোলন করে হার-জিতের ভিত্তিতে পয়েন্ট আদান-প্রদান আইনিভাবে জুয়া হিসেবে গণ্য হয় এবং এটা বাংলাদেশের আইনে ও পেমেন্ট গেটওয়ের নীতিমালাতেও নিষিদ্ধ। তাই এই ভার্সনে পয়েন্ট সম্পূর্ণ ইন-অ্যাপ স্কোর হিসেবে রাখা হয়েছে — কোনো রিয়েল-মানি ডিপোজিট/উইথড্র ফিচার নেই।

## ১. নিজের অ্যাডমিন অ্যাকাউন্ট খোলা

অ্যাপ চালু করার পর সবার আগে নিজের ইমেইল-পাসওয়ার্ড দিয়ে **রেজিস্ট্রেশন পেজ থেকেই** সাইন-আপ করুন — এটাই স্বয়ংক্রিয়ভাবে অ্যাডমিন অ্যাকাউন্ট হয়ে যাবে। (নিরাপত্তার কারণে পাসওয়ার্ড কোথাও কোডে বা ফাইলে হার্ডকোড করা হয়নি — আপনি নিজে অ্যাপের মাধ্যমে সেট করবেন।)

## ২. লোকালি চালানো (নিজের কম্পিউটারে টেস্ট করতে)

```bash
cd adapp
npm install
npm start
```
ব্রাউজারে যান: `http://localhost:3000`

## ৩. প্রোডাকশনে হোস্ট করা

এই অ্যাপে এখন রিয়েল-টাইম গেমের জন্য **Socket.IO** ব্যবহার হয়েছে, তাই এমন হোস্টিং লাগবে যেটা দীর্ঘস্থায়ী (persistent) সার্ভার প্রসেস চালাতে দেয় — যেমন:
- **Render** (render.com) — Web Service হিসেবে ডিপ্লয় করুন, Free/Starter টিয়ার Socket.IO সাপোর্ট করে
- **Railway** (railway.app)
- একটা সাধারণ VPS (DigitalOcean/Linode ইত্যাদি) + PM2

⚠️ Vercel/Netlify-এর মতো সার্ভারলেস প্ল্যাটফর্মে Socket.IO ভালোভাবে কাজ করে না — এড়িয়ে চলুন।

**ডিপ্লয় করার ধাপ (Render দিয়ে উদাহরণ):**
1. এই কোডটা একটা GitHub রিপোতে পুশ করুন
2. Render-এ নতুন "Web Service" বানান, রিপো কানেক্ট করুন
3. Build command: `npm install`, Start command: `npm start`
4. Environment ভ্যারিয়েবলে `JWT_SECRET` একটা লম্বা র‍্যান্ডম স্ট্রিং দিয়ে সেট করুন (ডিফল্ট ভ্যালু প্রোডাকশনে ব্যবহার করবেন না)
5. ডিপ্লয় শেষে পাওয়া URL-এ গিয়ে সবার প্রথমে নিজের অ্যাকাউন্ট রেজিস্ট্রেশন করুন

⚠️ **ডাটা স্টোরেজ নোট:** ইউজার ডাটা এখনো সাধারণ JSON ফাইলে (`data/users.json`) রাখা হয় — ছোট স্কেলের জন্য ঠিক আছে, কিন্তু বেশি ইউজার হলে বা সার্ভার রিস্টার্ট/রিডিপ্লয়ে ডাটা হারানো এড়াতে PostgreSQL/MongoDB-তে সরিয়ে নেওয়া উচিত। গেম রুমের অবস্থাও মেমোরিতে রাখা হয় (সার্ভার রিস্টার্ট হলে চলমান গেম হারিয়ে যাবে, কিন্তু ইউজারের পয়েন্ট নিরাপদ থাকে কারণ সেটা ফাইলে সেভ হয়)।

## ৪. গেম সিস্টেম কীভাবে কাজ করে

- **গেমস** পেজে গিয়ে লুডু বা তাশের জন্য যেকোনো আনলক করা টায়ারে "নতুন রুম" চাপলে একটা রুম কোড পাবেন
- সেই কোড বন্ধুদের পাঠান — তারা "গেমস" পেজ থেকে কোড দিয়ে জয়েন করবে
- ন্যূনতম ২ জন খেলোয়াড় হলে "গেম শুরু করুন" চাপা যাবে
- তাশ খেলায় ৪ আসনের কম হলে বাকি আসন সাধারণ বট (এলোমেলো চাল দেয়) দিয়ে পূরণ হয়ে যায়, যাতে কম মানুষ থাকলেও খেলা যায়
- খেলা শেষে বিজয়ী ও অংশগ্রহণকারীরা টায়ার অনুযায়ী পয়েন্ট পায় (`server.js`-এর `GAME_REWARDS` ও `ROOM_TIERS` অংশে সংখ্যাগুলো বদলানো যাবে)

⚠️ **নিয়ম সরলীকৃত:** লুডু ও তাশ দুটোই মূল খেলার সরলীকৃত সংস্করণ (যেমন তাশে কোনো বিডিং নেই, লুডুতে "কাটা" ও সেফ-সেল সরলীকৃত)। পুরোপুরি প্রচলিত নিয়মে বানাতে চাইলে জানাবেন, ধাপে ধাপে আরও নিখুঁত করা যাবে।

## ৫. Play Store-এ পাবলিশ করা

এটা এখনো একটা ওয়েব অ্যাপ। Play Store-এ দিতে হলে:
1. আগে উপরের ধাপে হোস্ট করে একটা রিয়েল URL বানাতে হবে
2. তারপর Android WebView র‍্যাপার বা React Native/Flutter দিয়ে প্যাকেজ করতে হবে

চাইলে পরের ধাপে এটা নিয়ে এগোতে পারি।
